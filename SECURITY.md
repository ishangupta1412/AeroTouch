# Security Policy

## Supported Platforms

AeroTouch interfaces directly with native operating system APIs (`user32.dll`, `oleacc.dll`) on Windows platforms.

| Operating System | Supported |
| :--- | :--- |
| Windows 11 (64-bit) | Yes |
| Windows 10 (64-bit) | Yes |
| Linux / macOS | Not Supported (Requires Win32 C-Interop) |

## Reporting Vulnerabilities

If you discover a security vulnerability or privilege escalation issue within AeroTouch's Win32 input synthesis pipeline, please report it privately:

- **Maintainer**: Ishan Gupta
- **Email**: ishan14122007@gmail.com

Please do not open public issues for sensitive security reports. Reports will be acknowledged within 48 hours, followed by coordinated patch deployment.
